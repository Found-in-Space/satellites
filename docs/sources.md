CELESTRAK ORBITAL DATA

Opt-in satellite groups request current General Perturbations orbital data
from CelesTrak:
https://celestrak.org/NORAD/elements/
https://celestrak.org/usage-policy.php

The application caches each source group for the provider's two-hour update
interval and does not bundle or redistribute a satellite catalogue.
